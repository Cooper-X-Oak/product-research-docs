# 最终综合

本组用于承接所有逐点调研之后的最终综合报告。当前站点已经有阶段性结论和机会决策页，但最终综合不能替代逐点调研，也不能引入前置页面没有出现过的新结论。

## 本组计划文档

```text
09_synthesis/
|
|-- executive_summary.md       执行摘要
|-- full_report.md             完整综合报告
`-- presentation_outline.md    汇报大纲
```

## 写作门槛

正式综合前，需要先补齐或确认：

- 中国市场地图中尚缺的 Agent workflow 平台、外贸工具和中国市场空白综合。
- MVP 计划组中的规格、demo、首单交付、14 天验证和转向标准。
- 全局证据台账中的来源、命令、失败渠道和质量矩阵已同步到最终引用。

最终综合的作用是压缩和组织证据，不是替代前面的逐点调研。
