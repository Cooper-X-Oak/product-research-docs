# AI CMO / Marketing Agent 产品机会调研

本目录是逐点调研工作区，不是单篇总报告。

核心原则：

```text
一页一个问题
一个问题一次全网调研
每个问题独立记录 agent-reach 命令、结果、失败渠道
先证据，后分析，再综合
总报告只做综合，不替代逐点调研
```

## 目录说明

```text
research/
|
|-- 00_methodology/          调研方法、渠道体检、信源分级、总查询日志
|-- 01_category_definition/  类目定义：AI CMO、Marketing Agent、GEO/SEO/社媒/B2B 边界
|-- 02_overseas_benchmarks/  海外产品标杆：Okara、Jasper、Copy.ai、Clay、Apollo 等
|-- 03_china_market_map/     中国市场地图：MarTech、SEO、社媒数据、本地商家、外贸工具
|-- 04_customer_scenarios/   客户场景：外贸 B2B、本地商家、独立站、通用 Agent 平台
|-- 05_pricing_willingness/  价格和付费意愿：工具价格、服务包、代运营、海关数据
|-- 06_technical_feasibility/ 技术可行性：agent-reach、浏览器自动化、平台约束
|-- 07_opportunity_decision/ 机会决策：标准、矩阵、推荐 MVP、风险
|-- 08_mvp_plan/             MVP 规格、首个 demo、首单交付、14 天验证、pivot 标准
|-- 09_synthesis/            最终综合：执行摘要、总报告、汇报大纲
`-- evidence/                来源、命令、失败渠道、来源质量、术语表
```

## 单页调研模板

每个调研点必须使用同一结构：

1. 本点要回答的问题
2. 为什么这个点重要
3. 调研方法
4. agent-reach 搜索记录
5. 关键来源
6. 关键发现
7. 分析和解释
8. 对 MVP 决策的影响
9. 结论
10. 置信度

## 验收口径

每个问题页最低要求：

- 至少 5 个有效来源。
- 至少 1 个非官网来源。
- 至少 1 条 agent-reach 平台命令记录。
- 至少 1 条失败或偏差记录；如果没有失败，也要写明未观察到失败渠道。
- 结论必须标注置信度。
