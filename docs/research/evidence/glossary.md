# 术语表

| 术语 | 工作定义 |
|---|---|
| AI CMO | 一种产品叙事或角色包装，声称用 AI 承担 CMO 式的营销判断、计划、执行、监控和复盘任务 |
| Marketing Agent | 面向营销任务的软件 agent，通常需要具备数据读取、推理、决策、工具调用和执行能力 |
| Agentic Marketing | 用 autonomous AI agents 重构营销工作流，使洞察、创意、个性化、投放、线索和复盘形成闭环 |
| AI CMO 叙事 | 把多个营销 agent 或工作流包装成“虚拟营销负责人”的产品定位方式 |
| 交付包 | 以人工审核和结果交付为核心的服务化 MVP，先卖可验证结果，而不是先卖平台账号 |
| 外贸 B2B 线索研究 | 面向出口/外贸企业，围绕目标市场、潜在买家、联系人、采购信号和触达建议形成研究交付物 |
