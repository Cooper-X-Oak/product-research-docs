# 来源分级

## 1. 分级原则

来源分级用于判断证据权重，不用于机械排除材料。产品官网可以证明“产品自称什么、提供什么”，但不能单独证明“市场真的需要什么”。

## 2. 来源等级

| 等级 | 类型 | 使用方式 |
|---|---|---|
| A | 官方文档、价格页、产品帮助中心、公开 API 文档 | 确认产品功能、边界、价格和官方定位 |
| A- | 权威咨询、研究机构、上市公司公告、可信行业报告 | 判断趋势、采用率、组织变化和风险 |
| B | 媒体评测、第三方工具目录、公开案例文章 | 辅助校验产品定位和市场叙事 |
| B- | Reddit、X、V2EX、B站、小红书等社区/平台内容 | 捕捉使用者反馈、实践语境、反例和噪音 |
| C | 个人博客、营销软文、服务商广告页 | 只能作为弱信号，需要交叉验证 |

## 3. 记录字段

每条来源至少记录：

| 字段 | 说明 |
|---|---|
| ID | 全局唯一来源编号 |
| 来源 | 页面或内容标题 |
| URL | 可访问链接 |
| 类型 | 官网、文档、第三方、社区、视频、价格页等 |
| 日期 | 发布日期或访问日期 |
| 关键证据 | 本项目使用该来源的原因 |
| 可信度 | 高 / 中 / 低 |
